# 我的世界弹弹乐

一个以方块击打、材料采集和基地防守为核心的四阶段网页肉鸽原型：从主世界采矿出发，穿越下界、守住反攻，最终进入末地击败末影龙。渲染采用 **Three.js 真实三维场景**；怪物、方块和道具使用从 Mojang 官方 **Minecraft Java Edition 1.21.5** 客户端提取的原版纹理。

原版素材不是开源资源，也不适用 Pixel Perfection 的 CC BY-SA 许可。来源、校验值和权利说明见 [原版素材记录](docs/VANILLA_ASSETS.md) 与 `assets/minecraft/sources.json`。当前尚未上传 Bilibili Toy 或提交平台审核。

## 启动

需要 Node.js；先安装项目依赖，再启动本地服务：

```powershell
npm install
npm start
```

浏览器打开 `http://127.0.0.1:4173/`。请通过 HTTP 服务运行，不直接双击 `index.html`。

## 四阶段流程

| 阶段 | 当前目标 | 前往下一阶段 |
| --- | --- | --- |
| 主世界 | 采集、合成装备，守住基地并攒够 **10 黑曜石**。 | 消耗黑曜石搭建下界门，等门升起后进入。 |
| 下界 | 对抗下界生物，收集 **12 末影珍珠＋12 烈焰粉**；烈焰人会掉落烈焰粉。 | 消耗上述材料搭建返程门，返回主世界。 |
| 主世界反攻 | 连续守住 **3 波，共 90 秒**。 | 村民援助的末地门自动升起，随后进入末地。 |
| 末地 | 逐个击破黑曜石护壳，摧毁 **4 座末地水晶**；水晶全部摧毁后末影龙出现。 | 基地存活并击败末影龙，完成本局。 |

顶栏显示当前目标与阶段进度；点击传送门或对应入口按钮即可使用。装备、材料、附魔和存活友军会随阶段推进保留，但雪傀儡进入下界时会融化；每个阶段重新开始计算波次，通关由上述目标推进决定。

## 玩法与操作

- **击球：**按住已有的持久方块，向出球方向的反方向拖拽；选中的方块停在手中，世界进入慢动作，松手出杆后恢复正常速度。新速度覆盖旧速度，摩擦会让方块明显减速。空地点击不会发射方块。
- **球杆：**`1–4` 切换已解锁的木棍、骨头、末地烛、烈焰棒。每次出杆记录当时的球杆效果和附魔；之后切杆不会改变已经击出方块的这次效果。
- **经验与材料：**击杀掉落绿色经验光球，由方块接触拾取；击打树木、矿石和消灭怪物还能获取合成材料。
- **升级三选一：**累计拾取经验达到升级门槛时暂停战斗，免费选择一项本局强化，支持 `1 / 2 / 3`。首个门槛为 5 XP，随后累计 14、28 XP；一次跨多级会依次选择。选择不消耗附魔经验，也不修改装备自身的附魔。工作台消费经验不会倒扣升级进度。
- **独立合成：**按 `C` 打开合成台，制作球杆、镐子、持久方块、TNT、道具、工作台及傀儡；根据配方消耗材料。
- **村民交易：**按 `E` 打开商店，按“材料 / 道具 / 友军 / 附魔书”分页购买，商品有每波库存。附魔书也可由怪物掉落：开局出售 2 本固定书，后续每波刷新 2–3 本随机书。
- **信标：**点击中央信标、按 `B` 或使用底部信标按钮，打开“信标能力 / 雇佣村民”面板。所有基地升级在这里查看与确认。
- **其他操作：**`R` 召回主方块，`P` / `Esc` 暂停；被末影人抓住的方块需要完成 QTE 解救。

### 运动接球与慢动作

接住正在高速运动的方块，会根据接速与连续接球获得下一击奖励，最高 **伤害 +60%、出速 +12%**，速度上限仍然有效。“精巧接球”等字幕随机演出，实际奖励以显示的数值为准，不会因文案或演出额外加成。奖励在成功出杆时才生效；取消瞄准会恢复原有运动，同一杆反复取消、重接不会刷取新的接球事件或连段。

普通球杆瞄准时世界速度为 **×0.30**，末地烛为 **×0.15**。“时缓”球杆附魔每级再乘 **0.8**，最高 IV 级，最低速度为 **×0.06**。只有被按住的方块固定，敌人、箭矢、采集村民及其倒计时继续按减慢后的时间推进。末地烛的特色是更强的慢动作；幽灵方块由“连击幻影”等对应效果产生。

### 信标能力与采集村民

信标从 1 级升至 5 级，金字塔基座从无底层逐步增加到 4 层。各级基础生命上限依次为 **120 / 150 / 190 / 240 / 300**，升级本体也恢复部分生命；堡垒修缮可额外提高上限。更高级的能力需要先达到对应信标等级，费用和门槛在面板中实时显示。

| 能力 | 作用 |
| --- | --- |
| 信标弹射 | 方块每次有效撞击信标，本轮伤害每级额外增加 12%。 |
| 急迫 | 每级提高铁傀儡、雪傀儡的攻击频率 18%。 |
| 挖掘速度 | 每级提高采集村民的工作频率 15%，与职业效率升级叠加。 |
| 震撼 | 怪物靠近时自动范围伤害并弹开，Boss 的击退较弱；升级提高范围、力度并缩短冷却。 |
| 防御与修缮 | 黑曜石护盾、生命再生、红石脉冲、回归震荡、堡垒修缮也统一在信标升级。 |

“雇佣村民”页有伐木与采矿两个职业：伐木村民自动找树，采矿村民自动寻找已落地的矿物。每个职业最多 2 人，总计最多 4 人，初始任期为 **60 战斗秒**；暂停不消耗任期，瞄准时按慢动作后的战斗时间消耗，任期结束后离开。

- 移动速度：每级提高 20%，影响在场与未来雇佣的本职业村民。
- 采集效率：每级提高工作频率 25%，与信标加成独立叠加。
- 雇佣期限：每级延长 20 战斗秒；已雇佣村民的剩余任期也增加 20 秒，最多升级 3 次。
- 独立工具：伐木村民升级斧头，采矿村民升级镐子，沿木、石、铁、钻石、下界合金进阶；两种职业和玩家的工具分别记录。

先选择能力或职业查看详情，再按右侧确认按钮扣除材料。材料变化与任期倒计时刷新不会重建选项按钮。

### 采矿与镐子

仍然用方块碰撞树木和矿石来采集。升级镐子会提高采矿伤害并缩短连续命中的间隔；镐子必须沿 **徒手 → 木镐 → 石镐 → 铁镐 → 钻石镐 → 下界合金镐** 逐级合成。推荐工具不是硬性门槛，低级工具也能开采硬矿，但速度会明显更慢。

| 资源 | 本游戏耐久 | 推荐工具 |
| --- | --- | --- |
| 树木 | 44 | 徒手 |
| 石头 | 80 | 木镐 |
| 铁矿、金矿、石英矿、末影珍珠矿 | 120 | 石镐 |
| 钻石矿 | 150 | 铁镐 |
| 远古残骸 | 300 | 钻石镐 |
| 黑曜石 | 480 | 钻石镐 |

资源硬度用于参考，表中耐久与工具效率是本游戏的平衡参数，不是原版 Minecraft 的破坏时间。战斗附魔、弹射与融合对采矿的额外增益合计封顶 20%；远古残骸与黑曜石还会分别吸收 92% 和 98% 的爆炸采集伤害，开采它们更依赖合适的镐子和重复碰撞。

| 合成目标 | 材料 |
| --- | --- |
| 木镐 | 3 木材 |
| 石镐 | 2 木材＋5 石料 |
| 铁镐 | 2 木材＋4 铁锭 |
| 钻石镐 | 2 木材＋3 钻石 |
| 下界合金镐 | 2 铁锭＋3 金锭＋4 合金碎片 |

主世界提供黑曜石等矿产，下界增加石英、金和合金碎片等资源；村民也会出售当前阶段需要的部分材料。

### 傀儡与下界高温

铁傀儡负责近战追击，雪傀儡用远程雪弹造成伤害和减速；每种最多两只。雪弹减速可配合“寒霜引雷”“霜火爆破”等附魔。**雪傀儡进入下界时会融化，下界也不能合成或雇佣雪傀儡**；返回主世界后可重新补充。

### 附魔与融合

先在 `C` 合成台制作工作台，解锁后使用界面按钮或快捷键进入：

| 工作台 | 合成材料 | 打开方式 |
| --- | --- | --- |
| 附魔台 | 2 钻石＋4 木材＋3 石料 | `F` / 附魔台按钮 |
| 铁砧 | 6 铁锭＋3 石料 | `G` / 铁砧按钮 |

附魔时先选一根球杆或一个持久方块。操作只影响选中的装备，每个目标最多持有 **4 种永久附魔**。基地能力通过信标面板升级，不再由三选一、装备附魔书或合成台的修缮配方提供。

| 操作 | 花费 | 结果 |
| --- | --- | --- |
| 附魔台随机重洗 | 8 XP | 替换目标原有附魔，重新获得 2 种一级附魔。 |
| 铁砧增量附魔 | 10 XP | 保留已有附魔，随机新增一种或把一种已有附魔升一级。 |
| 铁砧使用附魔书 | 3 XP＋1 本对应书 | 定向新增或升级该附魔；目标适用范围和等级上限仍有效。 |

铁砧也能把 **两个不同的持久方块融合为一个**，保留两者原生特性与附魔；同名附魔取较高等级。融合后超过 4 种附魔会被拒绝，融合等级最高为 3。含主方块的融合保留主方块及召回能力；幽灵方块、TNT 爆破方块和被抓住的方块不能融合。

### 粘液方块

击败普通史莱姆会获得**黏液球**：大型史莱姆掉落 2 份，其余体型掉落 1 份，分裂出的史莱姆也可继续掉落。商店每波提供黏液球材料包，花费 **1 铁锭＋2 石料**换取 3 份；在 `C` 合成台消耗 **3 黏液球＋2 石料**可锻造一块持久粘液方块。

粘液方块碰撞时保留更多速度，地面摩擦也更小，适合长时间弹射连锁，但仍会最终停下。粘液特性可通过融合永久保留，也能在方块互撞时临时共享；由它产生的幽灵分支同样继承弹性。将粘液方块改为炮台会形成“弹性光路”组合，让光束射程增加约 **20%–30%**，额外反弹 **2–4 次**，随粘液强化等级成长。

### 六种可叠加流派

操作栏下方的“当前构筑”小条可展开查看选中方块、球杆和本局强化的生效效果、等级与来源，只列出实际拥有的效果和已成型组合。查看时战斗继续；已射出的攻击保留出杆时的附魔。

| 流派 | 玩法与组合 |
| --- | --- |
| 火焰附加：传染火 | 命中点燃敌人，持续灼烧并向近邻传染；幻影、分叉光束和震波也能继承点燃。 |
| 冰霜触碰 / 寒冰特性：三击碎冰 | 连续命中叠加冰霜，由缓速、冻伤进入高伤碎冰；保留燃烧状态，可与霜火爆破共同构筑。 |
| 原地炮台 | 方块固定在原位，按住、反向拖拽瞄准并蓄力，松开发射反射光束。加入“连击幻影”后改为光束齐射，红石特性让命中触发链雷。 |
| 裂地者 | 命中释放范围震波与缓速；震波继承元素，可与引力聚怪、火冰效果叠加。 |
| 棱镜折射 | 普通出杆生成成对分叉幻影，炮台出杆分叉光束；分支继承元素与方块附魔。 |
| 引力印记 | 命中标记敌人并牵引附近怪物；被标记的敌人死亡后触发塌缩爆炸，适合接裂地与元素范围伤害。 |

炮台基础蓄力为 **0.85 现实秒**，轻巧握把和炮台等级可缩短蓄力；未蓄满不会发射。三选一点击“原地炮台”后，先从列表选择一个持久方块，再确认转换或升级；取消后保留原来的三张选项与选择次数。幽灵、TNT、被抓住、附魔槽已满且尚无炮台附魔的方块，以及已达炮台 III 级的方块不能选择。炮台附魔书仍只改变指定方块。

炮台不会被普通碰撞推走，仍可用召回、末影珍珠或阶段切换重新定位。光束会被墙壁、基地、其他持久方块、矿石和水晶反射；矿石与水晶同时受到伤害。光束穿过怪物，沿途也能拾取经验光球。

这些流派可以共同生效。火与冰不会相互清除，霜火爆破保留减速和冰霜；本局强化、球杆、方块和本轮继承的效果由构筑面板显示最终生效等级。原地炮台只对实际附有该效果的方块生效，不会让场上所有方块一起变成炮台。

### 弹射与本轮共享

正常持久方块在一次运动中不断反弹，会逐渐提高连锁伤害：

- 每次有效弹射基础增加 **8%** 伤害；“弹射增幅”每级再为每次弹射增加 **6%**。
- 每个额外参与过连锁的不同持久方块增加 **15%** 伤害。同一块反复加入不会重复计算人数。
- 每块只计算自己的弹射次数；连锁成员共享参与历史、原生特性和方块附魔，同名附魔取最高等级，也能传递临时燃烧。幽灵块和 TNT 不进入共享池。

例如，未触发信标额外增伤时，一块累计弹射 2 次、连锁涉及 3 块、有效“弹射增幅”为 II 级，连锁增伤为 `2 × (8% + 2 × 6%) + 2 × 15% = 70%`，对应伤害倍率 `×1.70`。

“弹力”附魔提高碰撞后的速度保留，让方块更容易继续反弹；强摩擦与速度上限仍然生效。正碰可能让其中一块自然停下，斜撞更容易让多块继续运动。

临时共享仅维持本轮运动。方块停稳、重新出杆、召回、被抓取、融合或跨地图后，会清除该方块的本轮记录；其他仍在运动的连锁成员可以保留已继承的效果。原有永久特性和附魔不会因此被替换。画面中的连锁光环与 HUD 显示当前实际倍率。

### 连锁、天气与敌人

雪球提供范围减速，烈焰弹造成范围伤害并点燃附近持久方块；它们能为“寒霜引雷”“霜火爆破”等附魔创造触发条件。末影珍珠可把选定方块瞬移到指定位置，红石过载在 10 秒内加快击球及元素触发节奏。

TNT 合成后直接成为场上的实体方块球，可以拖拽击打、推动与拾取经验。只有红石球或带红石特性的融合球与它发生有效碰撞时才引爆；普通撞击、墙壁、基地和火焰不会自行引爆。爆炸消耗 TNT，伤害范围内敌人并采集资源，不伤害基地或友军。

主世界和返程反攻会在波次推进时切换晴天、雨天、雷暴与黑夜。雨天和雷暴使火焰伤害降至 60%、雷电伤害增至 140%；黑夜提高出怪频率。雷暴会周期性落雷，放置避雷针可引导落点。怪物被击退后仍留在场内，场上敌人上限为 120。

各区域从第 1 波的 **×1.00** 开始，每多一波，新生怪物的生命与护盾倍率增加 **0.12**，例如第 2 波 ×1.12、第 3 波 ×1.24；切换阶段后重新计算。波次提升只影响之后生成的怪物，已在场的怪物不会因此加血或回满。顶栏会显示当前倍率。

| 敌人 | 需要留意的机制 |
| --- | --- |
| 唤魔者、恼鬼 | 唤魔者持续召唤数量受限的恼鬼，优先处理召唤源。 |
| 女巫、卫道士 | 女巫治疗附近怪物；持斧卫道士冲到基地会造成较高伤害。 |
| 溺尸、尸壳、持三叉戟溺尸 | 三叉戟是远程攻击，雨天伤害和速度增强，雷暴中命中还会引雷。 |
| 僵尸猪人 | 未被玩家伤害时保持中立；攻击一只会激怒本阶段的同类。 |
| 猪灵蛮兵 | 会优先靠近金块或保留金特性的融合块，可用金块作诱饵。 |
| 岩浆怪 | 大体型死亡后分裂，冲到基地还会留下短暂灼烧。 |
| 恶魂 | 用方块撞回它的火球，可以把攻击反弹回怪群。 |

主世界久留可能遇到循声守卫，下界可能出现凋零。末地以末影人和四座水晶为前置挑战，最终胜利目标始终是末影龙。

### 音乐与音效

背景乐是本项目新写的 Web Audio 配乐，随主世界、下界、末地切换音色和乐句，并响应天气、连击与 Boss 战。它不使用 Minecraft 原版 BGM 的录音或旋律；原版音乐的许可核验见 [音乐许可记录](docs/MUSIC_LICENSE.md)。

顶栏 `♫` 单独开关背景音乐，喇叭按钮控制全部声音，偏好保存在本机。首次开始或点击后才启用浏览器音频；暂停、切到后台或窗口失焦时停止持续播放。出杆、命中、木石采集、资源破坏、暴击、雷击、爆炸和雪傀儡融化分别有合成音效，连击会改变反馈节奏与音高。

## 当前技术状态

- 前端使用 JavaScript 模块和 Three.js，通过真实三维几何与 UV 贴图表现方块、角色和道具。
- 核心流程按主世界、下界、返程防守、末地四个阶段推进；合成、交易、附魔、融合及信标升级各有独立界面。
- 镜头适度拉近（约 18%），随画面宽高比自动调整，保证四周敌人入口可见。附魔台、铁砧采用独立三维场景，操作界面叠加在前景。
- 顶栏“光影 / 流畅”可切换画质。光影模式含暖色阳光、冷色天空环境、实时阴影、金属环境高光、水面波光与雾效、HDR 泛光；流畅模式跳过后处理并降低像素比和阴影分辨率。所有特效与依赖均随包提供。
- 原版纹理在 `assets/minecraft/`，逐文件记录源 JAR 路径、尺寸和 SHA-256；完整客户端下载缓存位于 `.cache/`，不属于运行素材。
- 本地记录由 `src/storage.js` 管理。**Toy 云存档和排行榜尚未实接**，不能把设备内记录当作跨设备存档或平台成绩。
- [Bilibili Toy 接入记录](docs/BILIBILI_TOY.md)提供平台上传结构、SDK 入口和测试流程；查阅流程不代表已经发布。

## 检查与打包

```powershell
npm test
npm run build
```

`npm test` 运行仓库自动化测试；实际通过情况以当前命令输出为准。构建目标产物：

- `dist/`：静态运行文件。
- `release/block-bounce-toy.zip`：网页打包产物，根目录直接包含 `index.html`。
- `release/manifest.json`：构建文件尺寸与校验记录。

以下 `.preview/` 页面是开发机器上保留的临时检查工具，未随仓库提交或随 Pages 部署；克隆仓库后请使用 `npm test` 和正式游戏入口验证。

开发机器上可打开 `http://127.0.0.1:4173/.preview/ricochet-render.html` 查看弹射对照：红石、寒冰、铁块使用真实物理完成斜撞，两组只改变“弹射增幅”等级；支持发射、慢放、三块连锁自动暂停和逐球统计。此夹具不在正式游戏入口或打包清单中。

`http://127.0.0.1:4173/.preview/aim-catch.html` 提供接球与慢动作对照，使用可见按钮发球、接球、推进现实时间、取消或出杆，并显示真实世界进度、敌人和村民运动、待生效及已提交的奖励；可比较木棍、末地烛与“时缓”附魔。此夹具同样不进入正式打包。

`http://127.0.0.1:4173/.preview/builds.html` 提供六流派及组合靶场，复用真实战斗、三维渲染和构筑面板；可直接拖拽方块，或通过可见按钮蓄力、精准出杆、推进到命中并冻结画面，查看光束、伤害、燃烧、冰层和引力状态。预设只用于本地检查，不进入正式游戏或存档。

## GitHub Pages 部署

仓库为 [YaoYao-Pig/MCBalls](https://github.com/YaoYao-Pig/MCBalls)。配置 Pages 并完成首次成功部署后，预计可通过 [我的世界弹弹乐网页版](https://yaoyao-pig.github.io/MCBalls/) 游玩；工作流文件存在不代表网站已经上线，实际部署地址与结果以 GitHub Actions 的 `github-pages` 环境为准。

[自动部署工作流](.github/workflows/deploy-pages.yml)在推送 `main` 时运行，也支持在 Actions 页面手动触发并选择 `main`。它使用 Node.js 24，依次执行 `npm ci`、`npm test`、`npm run build`；测试和构建成功后，只将 `dist/` 上传并部署。运行文件使用相对路径，以适配 `/MCBalls/` 项目路径。并发发布按同一组排队，正在进行的部署不会被新推送中断。

首次配置需在仓库 **Settings → Pages → Build and deployment → Source** 选择 **GitHub Actions**；之后向 `main` 推送或手动运行工作流。发布使用 GitHub 自动提供的工作流凭据，无需在仓库中保存个人访问令牌。配置方法见 [GitHub 官方 Pages 工作流说明](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages)和[发布来源设置](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)。

GitHub Pages 部署与 Bilibili Toy 发布分别进行。生成 ZIP 只表示完成打包；当前尚未完成 Toy SDK 接入、上传 Toy 或通过平台审核。

Toy 发布前仍需在 B站真实容器验证触控、三维性能、安全区和子路径资源加载。文档不将尚未执行的检查标为通过。
